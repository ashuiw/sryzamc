# Paper comparison protocol

The Criterion benchmark is a scheduler data-structure microbenchmark only. It is not comparable to Paper and measures neither TPS nor end-to-end performance.

For a future fair comparison, publish exact server build IDs, toolchain/JVM versions, OS, hardware, flags, plugins, world seed, player bot paths, duration, warmup, and raw samples. Run both on one host with equivalent behavior and repeat at least five times. Report median and tail tick duration, MSPT percentiles, throughput, memory, GC/allocator activity, disk I/O, and errors.
