# Roadmap

1. Buildable foundation: CI, config validation, CLI, protocol tests.
2. Version-pinned status/login, authentication, encryption, rate limits, vanilla client tests.
3. Verified Anvil/NBT storage, crash-safe saves, migration fixtures.
4. Playable vanilla: registries, chunks, simulation, commands, permissions, shutdown.
5. JVM bridge and core Bukkit API with lifecycle/event/scheduler semantics and real plugin suite.
6. Incremental Spigot/Paper API coverage and published compatibility matrix.
7. Profiling-guided optimizations measured against equivalent Paper builds and behavior.
8. Signed cross-platform releases, installer/upgrade/rollback, SBOM and security process.

Do not claim TPS gains or plugin compatibility until equivalent workloads and tests support the claim.
